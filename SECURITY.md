# Security

If you find a security problem, please report it privately through GitHub: **Security → Report a vulnerability** on this repository. Please don't open a public issue for it.

When you self-host, you are responsible for your own deployment: keep `MFA_ENCRYPTION_KEY` secret, keep Wrangler up to date, and consider closing sign-ups (`REGISTRATION_OPEN` = `"false"`) once your people have accounts.
